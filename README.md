# Quick Restart
Mod for quickly reloading rooms in Slay the Spire 2 for the classic save scumming experience. Supports both english and simplified chinese.

## Usage
When opening the pause screen (escape) there will be a new button "Restart Room" that will reload the current room and undo everything since the last auto save. Additionally, you can hold down the restart key (R by default but can be rebound in mod config) for a configurable amount of time to restart,

This can be used to undo event choices or combats as long as they're not completed already.

## Configuration  
In the mod config menu from BaseLib you can configure the following things:
- How long to hold the restart key before restart
- Whether to show the radial indicator while the button is held down
- Rebinding the restart key

## Installation
Use the steamworkshop to install this mod, the releases are outdated.
